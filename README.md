# 🏮 Lantern Academy (LA)

เกมผจญภัยเรียนรู้สำหรับครอบครัว · เล่นบนเว็บ ติดตั้งเป็นแอปได้ (PWA) · เล่นออฟไลน์ได้
**เล่น:** https://phoneyjung.github.io/Leah-PP/

ผู้เล่นเป็นนักเรียนของ **Lantern Academy** ในเมืองพาเพลิน ฝึกเป็นผู้พิทักษ์แสง ตอบคำถามปลุกคริสตัล ช่วยผู้พิทักษ์ 6 ดินแดนที่ถูกหมอกเทาทำให้ง่วง ลืม และเหนื่อย แล้วนำแสงกลับคืนสู่โลก
- **เด็ก (6–11):** ทักษะชีวิต 5 อย่าง · เครื่องมือ 5 ชิ้น · จบเรื่องได้ด้วยการตอบคำถาม (คริสตัลผู้พิทักษ์)
- **ผู้ใหญ่ (12+):** อาชีพ 4 สาย เลื่อนขั้น 3 ขั้น · ปราณ · ของดรอปแบบ Diablo · ดันเจี้ยนสุ่ม · ออโต้แบบจำกัด
- **ครอบครัว:** เล่นหลายคนในเครื่องเดียว · ออนไลน์ห้องเดียวกัน (Firebase) · กล่องของขวัญครอบครัว

ชื่อย่อ **LA** มาจาก **ลีอา** เด็กคนแรกที่เกมนี้ทำให้
