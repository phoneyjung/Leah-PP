- **ไฟล์หาย:** วาดรูปทรงสำรองทุกชิ้น (ไทล์เป็นสีพื้น · บ้าน ต้นไม้ เสาไฟ สไลม์ ถ้ำ) เดินได้ตามปกติ ไม่จอขาว
