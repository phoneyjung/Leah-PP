## 1. อาการ
- ฉากถ้ำ (`?gm` ถ้ำ) เมื่อ canvas สูงไม่ถึง 192 px จริง (px ของเครื่อง ไม่ใช่ CSS px) → error → หน้าหยุดวาด จอว่าง
- ขยายจอกลับแล้ว**ยังว่าง** ต้องโหลดหน้าใหม่
- ฉากสว่าง/มืด ไม่ error แต่ไม่เห็นตัวละคร (ขยายกลับแล้วหายเอง)

## 2. สาเหตุ (ตามลำดับ)
1. **`scale()` บรรทัด 126:** `Math.round(cv.height/384)*ST.zoom` · canvas สูง 0–191 px → `Math.round` ได้ 0 → **s = 0**
2. **ชั้นความมืดถ้ำ บรรทัด 178:** `aw=Math.ceil(cv.width/s)+3` และ `ah=Math.ceil(cv.height/s)+3` หารด้วย 0 → ได้ Infinity (หรือ NaN เมื่อ canvas กว้าง/สูง 0) · **บรรทัด 179** ตั้ง `dc.width=aw` แล้ว canvas ชั้นมืดกลายเป็นขนาด 0
3. **บรรทัด 185:** `g.drawImage(dc,…)` วาด canvas ที่กว้าง 0 → เบราว์เซอร์โยน `InvalidStateError`
4. **บรรทัด 208:** `loop()` เรียก `draw()` ก่อน `requestAnimationFrame(loop)` → error ใน `draw()` ทำให้ไม่ได้จองเฟรมถัดไป → **วงวาดหยุดถาวร**
5. ขยายจอ → `resize()` ยังทำงานและล้าง canvas แต่ไม่มีใครวาดใหม่ → จอว่างจนโหลดหน้าใหม่
6. ฉากสว่าง/มืด: s = 0 ไม่มีจุดที่โยน error แต่ทุกอย่างถูกวาดขนาด 0 → เห็นแค่พื้นหลัง (และป้าย GM)

**ต้นเหตุจริง:** หน้า Pilot ลอกสูตรมาจากเกมแต่ตก `Math.max(1, …)` · เกมจริง `index.html` บรรทัด 400 ใช้ `SC=Math.max(1,Math.round(dh/384))` (เหมือน `proto2d.html` `proto-plaza.html` `proto-mountain.html`)

## 3. ใครเจอได้
- มือถือแนวนอน 844×390 @ DPR 2.625 → canvas สูง 1024 → s = 3 → **ไม่เกิด**
- เกิดเมื่อพื้นที่หน้าเว็บสูงไม่ถึง 192 px ของเครื่อง: DPR 1 = หน้าต่างเตี้ยกว่า 192 CSS px · DPR 2.625 = เตี้ยกว่า 73 CSS px (เช่น แบ่งจอ · เปิด DevTools · หน้าต่างย่อเล็ก) · หน้านี้ไม่มีช่องพิมพ์ จึงไม่น่าเกิดจากแป้นพิมพ์

## 4. ร่างแก้ (จุดเดียว · 1 บรรทัด)
- `scale()` = `Math.max(1,Math.round(cv.height/384))*ST.zoom` → สูตรเดียวกับเกมจริง
- canvas สูง ≥ 192 px: ค่า s **เท่าเดิมทุกกรณี** (Math.round ≥ 1 อยู่แล้ว) → ภาพเดิมทุกพิกเซล
- canvas สูง < 192 px: s = 1 (ซูม 100%) หรือ 0.75 (ซูม 75%) แทน 0 → ไม่มีการหารด้วย 0 · ชั้นมืดมีขนาดจริง · ไม่ error · วงวาดไม่หยุด
- ค่า 0.75 ตอนซูม 75% บนจอเล็ก = ค่าเดียวกับเกมจริง (`index.html` บรรทัด 2501–2502 ซูมไม่ต่ำกว่า 0.5 · ฐาน 1 × 0.75) และเท่ากับที่หน้า Pilot ใช้อยู่แล้วที่ canvas สูง 192–575 px
- จุดที่หารด้วย s ทั้งหมด (บรรทัด 147 178 182 183 190) ปลอดภัยเมื่อ s ≥ 0.75
- ไม่แตะบรรทัดอื่น: ไม่แก้ C Pool · V0 · O13 · G18-b2 · ไม่แก้ป้าย GM ("ชั่วคราว" = Minor UI Text Debt แยกไว้)

## 5. ทางที่ไม่เลือก (บันทึกไว้)
- ใส่ `s>0` กันที่บรรทัดถ้ำ 2 จุด (ข้อเสนอเดิมใน O3): กัน error ได้ แต่ s ยังเป็น 0 → ตัวละครยังหายบนจอเล็ก · ต้องแก้หลายจุด
- ครอบ `draw()` ด้วย try/catch ใน `loop()`: ซ่อนอาการ ไม่แก้ต้นเหตุ
