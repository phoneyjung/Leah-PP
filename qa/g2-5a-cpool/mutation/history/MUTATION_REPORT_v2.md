## ข้อที่ ChatGPT ให้ตรวจ
- **ฐานพลัง 10 ไม่ได้ทำให้ผ่านเอง:**
  - หน้าเดิม 1c40891 รัน v2 ได้ 21/24 · ตก G5b G8 G13
  - MUT-6 (ไม่มี C ที่ 10) ตก 5 ข้อ
  - MUT-7/8 (Glow / caveHole ที่ 10) ตก G4b + G5
- **แยก Glow ออกจาก C:**
  - G4b วัด "10% ไม่มี Glow" ด้วยการบังคับ Glow = 0 ที่พลัง 10 แล้วเทียบ · C อยู่ทั้งสองภาพจึงหักกันหมด → MUT-7 ต่าง 33,894 px
  - G5 เทียบเปิด/ปิด FX ที่พลัง 10 · Glow และ caveHole รั่ว → มีพิกเซลนอกช่องตัวละคร หรือฉากสว่างมีพิกเซลเปลี่ยน
- **พลัง 10% ต้องไม่มี Glow และ caveHole:** MUT-7 และ MUT-8 จับได้
  - **ข้อเสนอเสริม (ยังไม่ทำ):** เพิ่มการตรวจค่าสถานะ `glow=false` และ `caveHole=0` ที่พลัง 10 ตรง ๆ ใน G5b
  - ตอนนี้จับได้ทางพิกเซลอยู่แล้ว
- **C ต้องมีเมื่อเงื่อนไขครบ:** G5 และ G5b ที่พลัง 10 และ 100 → MUT-6 จับได้
- **C ต้องไม่มีที่พลัง 0 / ไม่ถือ / ทิศ N / ปิด FX / ชั้นแสงหาย:** MUT-1 ถึง MUT-5 จับได้ทุกตัว
- **ตรวจทั้งพื้นมืดและถ้ำ:** G5b ตรวจทั้งสองฉาก · ตารางเงื่อนไขครอบคลุมทั้ง 3 ฉาก
