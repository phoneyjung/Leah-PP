### โหมด GM ทำอะไร
- **ตะเกียง:** ใช้ตะเกียง L0 ทิศ S จริงแทนตะเกียงตัวแทนชุด 08
  - โค้ดคัดลอกช่อง S ไปทุกคอลัมน์ตอนโหลด ไฟล์ภาพไม่ถูกแก้
  - จุดจับเอาจาก json (`[16,6]`)
- **พลัง** (แผน G2.5 ข้อ 6):
  - 100%: แสงในโคมเต็ม และ Glow เต็ม
  - 50%: แสงในโคมเต็ม · Glow ครึ่งหนึ่ง
  - 10%: เหลือประกายในโคม 35% · ไม่มี Glow
  - 0%: กระจกมืด · ไม่มีแสง
- **ลำดับวาด:** เงา → C (พื้นมืด) → Glow (มีแสงเท่านั้น · อยู่หลังตัว) → ตัว → ตะเกียง → ชั้นแสงตามพลัง → กำปั้นทับห่วง
- **ถ้ำ:** ความมืดทับทั้งจอ และเลื่อนตามกล้อง
  - เจาะรูตามแสงตะเกียง (ตามพลัง) และตาม C
  - วาดแสงในโคมซ้ำให้ไม่มืด โดยกำปั้นยังอยู่หน้าแสง
  - รัศมีแสงในถ้ำเป็นค่าชั่วคราว
- **ทิศ N:** ไม่มีตะเกียง ไม่มี Glow ไม่มีแสงในถ้ำ (ตรงกับแบบ ก ในแผนข้อ 6 · ยังรอเจ้าของเลือกแสงทิศ N)
- **ปุ่ม:**
  - ปุ่มใหม่: "พลัง" (100 → 50 → 10 → 0) · "Glow+C เปิด/ปิด"
  - ปุ่มพื้นวนเป็น สว่าง → มืด → ถ้ำ
- **ป้าย GM มุมซ้ายล่าง:** บอกว่าใช้ภาพ S ทุกทิศชั่วคราว พร้อมระดับพลัง
- **ไฟล์หาย:**
  - ภาพหลักหรือ json หาย → ซ่อนตะเกียง และไม่ใช้ชุด 08
  - ชั้นแสงหาย → ตะเกียงไม่มีแสง ไม่มี Glow ไม่มีแสงในถ้ำ
  - พื้นถ้ำหาย → ยังวาดได้
- **แก้บั๊กเดิม:** ปุ่ม Offset / ซูม / พื้น / ป้าย / เส้นช่วย กดไม่ได้มาตั้งแต่ก่อน เพราะถูกคอมเมนต์ท้ายบรรทัดกลืนไป ตอนนี้กดได้แล้ว
